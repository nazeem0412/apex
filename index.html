/ Interface

One core, four moods

The desktop interface changes colour and motion with what Jarvis is doing, so its state reads at a glance from across the room.

  1. Blue

    Idle

    Standing by and ready. The core breathes slowly and the rings drift while Jarvis waits for the next request.

  2. Amber

    Thinking

    Working on a request. Everything turns amber, the rings speed up, and the tool being used shows under the core.

  3. Blue, live

    Speaking

    Answering out loud. The core pulses with the voice and the voice meter moves with every word.

  4. Grey

    Held

    Kill switch engaged. Every background action is paused and the whole interface goes grey until it is released.

Red appears only when the AI service is rate-limited.

/ Security and privacy

The owner stays in control

Jarvis runs on its owner's own computer. Nothing is sold, shared or used for advertising.

  • Asks before acting. Anything that changes files, sends, clicks or deletes needs approval first.
  • Approval password. The most sensitive actions need a password only the owner knows, never spoken aloud.
  • Kill switch. A single command pauses every background action instantly.
  • Privacy dashboard. See everything Jarvis keeps, and delete any of it.
  • Offline backups. Daily, checked backups to a USB drive in the owner's hands.
